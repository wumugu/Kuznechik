# Кузнечик и числа Коллатца

Задача F из контеста: кузнечик Кузя строит последовательность Коллатца для числа 17, складывает числа в стопку и прыгает по числовой прямой. Нужно определить, в какой точке он остановится.

## Условие

Последовательность Коллатца для `n`: если число чётное, делим его пополам, иначе утраиваем и прибавляем единицу. Заканчивается на единице. Для 17:

```
17, 52, 26, 13, 40, 20, 10, 5, 16, 8, 4, 2, 1
```

Листочки с этими числами сложены в стопку: сверху 17, затем остальные по порядку.

Кузя стоит в точке 0 и прыгает:

- Смотрит на число сверху стопки и прыгает на столько позиций.
- Нечётный по номеру прыжок идёт вправо, чётный влево (прыжки нумеруются с единицы).
- После прыжка верхний листочек кладётся вниз стопки.
- Процесс останавливается, когда Кузя второй раз оказывается в одной и той же точке.

Первый прыжок приводит в точку 17, второй в точку -35.

Входных данных нет, нужно вывести одно число: точку, в которой остановится Кузя.

## Ответ

```
11
```

## Идея решения

Стопка с перекладыванием верхнего листочка вниз это циклический список из 13 чисел, поэтому на прыжке с номером `j` берётся элемент `seq[(j - 1) % 13]`. Дальше простая симуляция: храним множество уже посещённых точек и останавливаемся на первой повторной.

Путь Кузи:

```
0, 17, -35, -9, -22, 18, -2, 8, 3, 19, 11, 15, 13, 14, -3, 49, 23, 36, -4, 16, 6, 11
```

На 21-м прыжке он второй раз попадает в точку 11. Начальную точку 0 можно считать посещённой или нет, ответ в обоих случаях одинаковый.
